# Inverse-Kinematics-for-Manipulator
Проект: Решение задачи обратной кинематики для 6-ти звенного робота манипулятора при помощи нейросети
Обратная кинематика — это поиск углов поворота суставов, чтобы конечный эффектор достиг нужной позиции и ориентации. Традиционные методы сложны и медленны, поэтому здесь используется нейросеть для мгновенного предсказания решений.

Задачи:
1) Сбор данных
Собираються данные об углах манипулятора для случайных точек.
2) Обучение нейросети
Обучение нейросети на основе полученных данных
3) Использование

Преимущества:

-Высокая скорость работы.

-Нет необходимости решать сложные уравнения в реальном времени.

-Поддерживает несколько возможных решений для одной цели.
